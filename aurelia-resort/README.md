# AURELIA — Boutique Resort & Spa

A fictional luxury boutique resort concept built for a frontend portfolio with HTML5, CSS3, Bootstrap 5, and vanilla JavaScript.

## Project structure

```text
aurelia-resort/
├── index.html
├── css/
│   ├── variables.css
│   ├── style.css
│   └── responsive.css
├── js/
│   ├── main.js
│   ├── gallery.js
│   ├── booking.js
│   └── theme.js
├── README.md
├── .gitignore
└── .gitkeep
```

## Notes

- This stage establishes the project foundation and base architecture.
- The design uses free stock imagery from Unsplash for a premium resort aesthetic.
- The site is prepared for static deployment on GitHub Pages.
- The next steps will focus on refining the sections and visual polish.
